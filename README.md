# AI-Generated Voice Detection API (Multi-Language)

This project provides a RESTful API that determines whether an input voice sample is generated by artificial intelligence or spoken by a real human. The system is language-agnostic and supports multiple Indian and global languages.

---

## 1. Problem Statement

Advancements in text-to-speech and voice cloning technologies have made it increasingly difficult to distinguish between real human speech and AI-generated audio. This poses risks in areas such as fraud, misinformation, impersonation, and digital security. A reliable and explainable detection mechanism is required to address these challenges.

---

## 2. Solution Overview

The proposed solution is an API-based voice analysis system that processes an audio sample and classifies it as either AI-generated or human speech. The system combines classical audio signal processing techniques with a lightweight machine learning model to produce a probabilistic and explainable result.

Supported languages include:
- Tamil
- English
- Hindi
- Malayalam
- Telugu

---

## 3. System Architecture

1. Client sends a Base64-encoded audio file (MP3 or WAV) to the API.
2. The server decodes the audio and normalizes it for analysis.
3. Acoustic features are extracted from the signal.
4. A trained machine learning model estimates the likelihood of synthetic speech.
5. A rule-based fallback mechanism handles ambiguous cases.
6. The API returns a structured JSON response with classification and confidence.

---

## 4. Feature Extraction

The system extracts the following acoustic features:
- Fundamental frequency statistics (pitch mean and variance)
- Mel-Frequency Cepstral Coefficients (MFCCs)
- Spectral centroid
- Root Mean Square (RMS) energy variation
- Zero-crossing rate

These features are commonly used in speech and audio forensics.

---

## 5. Machine Learning Approach

- Model: Logistic Regression
- Feature scaling: StandardScaler
- Training strategy:
  - Balanced class weighting
  - Probabilistic thresholds to avoid over-classification
- Inference:
  - Direct model prediction for confident cases
  - Rule-based decision for borderline cases

This hybrid approach improves robustness and interpretability.

---

## 6. API Specification

### Endpoint
```

POST /api/voice-detection

```

### Headers
```

x-api-key: <API_KEY>
Content-Type: application/json

````

### Request Body
```json
{
  "language": "English",
  "audioFormat": "wav",
  "audioBase64": "<FULL_BASE64_AUDIO_STRING>"
}
````

### Response Body

```json
{
  "status": "success",
  "language": "English",
  "classification": "AI_GENERATED",
  "confidenceScore": 0.82,
  "explanation": "ML model detected synthetic voice patterns"
}
```

---

## 7. Output Description

* **classification**
  Indicates whether the voice is AI-generated or human.

* **confidenceScore**
  A floating-point value between 0.0 and 1.0 representing prediction confidence.

* **explanation**
  A short human-readable description of the detection rationale.

---

## 8. Deployment

The API is deployed on Hugging Face Spaces using a Docker-based setup with CPU inference. This ensures a publicly accessible, stable endpoint suitable for automated evaluation.

---

## 9. Limitations

* High-quality AI-generated voices may occasionally resemble human speech closely.
* Short or noisy audio samples can reduce prediction confidence.
* The system prioritizes robustness and explainability over aggressive detection.

These limitations reflect real-world constraints in synthetic voice detection.

---

## 10. Applications

* Voice-based fraud detection
* Scam and impersonation prevention
* Media and audio forensics
* AI safety and compliance checks
* Speech authentication systems
